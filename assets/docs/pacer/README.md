# PACER Documents

This directory contains PACER documents for the Copeland v. Weinstein case and related legal filings.

## File Naming Convention
To keep things organized and easy to link, please use the following naming convention:
`YYYY-MM-DD-Document-Description.pdf`
Example: `2026-05-13-Verified-Complaint.pdf`

## How to Link on the Website
To link to a document in this folder from your HTML pages, use a relative path like this:
`<a href="/assets/docs/pacer/2026-05-13-Verified-Complaint.pdf" target="_blank">View Verified Complaint</a>`
